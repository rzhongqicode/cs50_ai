# CS50's Introduction to Artificial Intelligence with Python - 课程项目与笔记

## 简介

欢迎来到我的 CS50's Introduction to Artificial Intelligence with Python 课程项目仓库！

本仓库包含了哈佛大学 CS50 AI 课程的所有项目代码。设立这个仓库的目的是记录我的学习过程，并为正在学习本课程的同学提供一份参考资料。希望我的实现思路和代码能帮助你更好地理解课程内容，或在你遇到困难时为你提供一些启发。

该课程涵盖了现代人工智能的许多核心概念，包括：
* 搜索算法 (Search)
* 知识表示 (Knowledge)
* 不确定性推理 (Uncertainty)
* 优化 (Optimization)
* 机器学习 (Learning)
* 神经网络 (Neural Networks)
* 自然语言处理 (Language)
